# Referencia visual del mockup

`mockup.pdf` conserva las 38 páginas del adjunto, con su tamaño y contenido visual.
Se renderizó a 3840 × 2160 píxeles por página (144 dpi) y se incorporó como imágenes PNG
sin compresión con pérdida. Esta copia permite versionar la referencia en GitHub.
Su texto está rasterizado; para extraer texto o editar vectores se debe consultar el original.

El original suministrado, `Mockup (diseño).pdf`, pesa 302606548 bytes y se conserva sin modificar
en la carpeta Descargas del usuario. No se incorpora ese archivo de 289 MiB al historial Git.
SHA-256 del original: `c3f9140bc709604971779fe6479914196b0c548991146022734939621936b5ea`.
